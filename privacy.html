1. 프로그램의 목적

본 프로그램은 블로그·뉴스 수집 결과를 Excel 파일로 저장하고, 사용자가 지정한 Google Drive 폴더에 업로드하기 위해 사용됩니다.

2. Google 사용자 데이터 접근 및 이용

사용자의 동의를 받아 부여된 Google Drive 권한을 사용하며, 생성된 결과 파일의 업로드와 관련 파일 정보 확인을 목적으로 이용합니다. Google 사용자 데이터를 광고나 판매 목적으로 이용하지 않습니다.

3. 데이터 저장 및 보호

결과 파일은 프로그램 실행 환경과 지정된 Google Drive 폴더에 저장됩니다. OAuth 인증 정보는 로컬 인증 파일 또는 GitHub Actions Secrets에 보관하며, 공개 웹페이지나 공개 저장소에 게시하지 않습니다.

4. 데이터 공유

프로그램 실행과 파일 저장을 위해 Google 및 GitHub 서비스를 이용합니다. Google 사용자 데이터를 별도로 판매하거나 광고업체에 제공하지 않습니다.

5. 보관 및 삭제

저장된 결과 파일은 사용자가 업무상 필요한 기간 동안 보관하며 직접 삭제할 수 있습니다. 프로그램 사용을 종료할 때 로컬 인증 파일과 GitHub Secrets의 인증 정보를 삭제할 수 있습니다.

6. 접근 권한 철회

Google 계정의 보안 설정에서 본 프로그램의 연결 및 접근 권한을 철회할 수 있습니다. 권한 철회만으로 기존 업로드 파일이 삭제되지는 않습니다.
